FinalBot technical changelog

Routing, execution, risk, telemetry, and wallet-watching upgrades.

This page only covers technical bot features: trade routing, latency improvements, fallback systems, risk controls, simulation fixes, observability, and analysis tools.

Direct Pump.fun and PumpSwap routing paths
Faster gRPC, RabbitStream, WS, raw transaction parsing
Safer Risk exits, circuit breakers, position caps
Observable Execution telemetry, JSONL logs, analysis scripts

Execution And Routing

Core trading engine
01

Direct Pump.fun Buys

Fresh pump.fun bonding-curve tokens can bypass Jupiter. The bot derives the curve, quotes locally, sizes the buy, builds the instruction, and broadcasts directly.

02

Source Buy Replay

For hot pump.fun launches, the bot can replay source buy instruction data and scale it to our configured buy size, reducing dependency on slow indexing.

03

PumpSwap Direct Routes

Graduated pump.fun tokens can use canonical PumpSwap direct buy/sell builders instead of relying only on Jupiter routes.

04

Jupiter Rescue Path

Jupiter remains available as fallback. Failed direct buys can attempt one Jupiter rescue, and quote throttles protect against rate limits.

05

Size-Safe Transactions

Transaction building now handles oversize routes more carefully with compact builders, ALT support, account limits, and route-aware transaction construction.

06

Jito / Sender Landing

Broadcasts can use Helius Sender and optional direct Jito BlockEngine submission, with route-specific tip multipliers and fallback behavior.

Speed And Detection

Signal ingestion
07

Multi-Feed Watchers

The bot can listen through Shyft gRPC, RabbitStream, Helius transactionSubscribe, wallet logsSubscribe, polling fallback, and the Rust sidecar.

08

Raw Transaction Fast Path

WS-detected signatures can be parsed from raw RPC transactions before slower enhanced transaction APIs catch up.

09

Rust Sidecar

A Rust pump.fun sidecar can provide faster low-level detection for fresh launches, feeding swaps back into the TypeScript bot.

10

ALT Cache

Address lookup tables are cached so repeated Jupiter-style routes do not waste time fetching the same lookup tables.

11

Direct Balance Reads

Sells use direct associated-token-account balance lookup first, then fall back to slower full token-account scans when needed.

12

Signature Dedupe TTL

Processed signatures are bounded and swept over time, preventing long sessions from growing memory forever.

Risk And Position Controls

Exits and guardrails
13

Exit Signal Wallets

Optional sell-only wallets can be watched. Their buys are ignored; their sells can close our matching open mint. Disabled by default.

14

Mirror Sells Toggle

Source-wallet sell mirroring can be toggled separately from buy mirroring, allowing manual exits or exit-signal exits.

15

Tiered Risk Checks

Positions are checked in fast, near-trigger, and normal buckets, so fresh or risky positions get more attention without overloading quote APIs.

16

TP / SL / Trailing Steps

Stop-loss, take-profit, minimum hold time, and stair-step trailing stops can all be configured from env.

17

Position Caps

Controls include max open positions, max SOL per token, max buys per token, and buy-once-per-token mode.

18

Circuit Breakers

Optional daily loss and consecutive-loss controls can pause new buys while still allowing sells.

Entry Quality And Simulation

Fill quality
19

Soft Impact Cap

Instead of skipping every high-impact quote, the bot can reduce size and retry until the entry fits the configured impact limit.

20

Source Drift Check

Optional guardrail to skip buys when our quote is too far above the source wallet's actual fill price.

21

Shadow Execution

Paper trading can model latency, entry slippage, exit slippage, flat fees, failure rate, and RPC simulation behavior.

22

Fresh-Launch PnL Fix

Pump.fun simulation now estimates replay-buy token output instead of using a placeholder, improving open-position and PnL tracking.

23

Dust-Safe Paper Fills

Shadow execution no longer rounds a positive simulated buy output down to zero tokens.

24

Preexisting Mint Filter

Startup scan can skip mints already held or recently bought by the source wallet before this bot session began.

Observability And Tooling

Debugging and analysis
25

Execution Telemetry

The bot records execution-plan and route diagnostics, with a report script available from npm.

26

Persistent Trade Logs

Trades can be written to JSONL with details that make post-session review and PnL debugging easier.

27

Telegram Controls

Telegram notifications and commands support bot monitoring, PnL reporting, and position management.

28

Wallet Cluster Tools

New scripts inspect wallet relationships, token transfers, first buys, first sells, and source/outlet wallet behavior.

29

Wallet Performance Audits

Analysis scripts can review wallet PnL, ATH behavior, quant-style exit ideas, and source copyability.

30

License System

License API, license admin commands, machine reset, revoke, list, and local test scripts exist for friend/distribution builds.

Key Config Flags

Env-driven features
PUMPFUN_DIRECT_ENABLED=true

Use direct pump.fun route for pre-graduation bonding-curve tokens.

PUMPFUN_EXACT_SOL_IN_BUYS=true

Use exact-SOL-in direct buys for pump.fun curve entries.

PUMPSWAP_DIRECT_BUY_ENABLED=true

Use PumpSwap direct buys for graduated tokens when appropriate.

FAILED_BUY_RECOVERY=JUPITER_ONCE

Try one Jupiter fallback after a failed direct buy.

EXIT_SIGNAL_SELLS_ENABLED=false

Optional sell-only outlet-wallet exit system. Currently disabled.

MAX_ENTRY_PRICE_IMPACT_PCT=60

Soft cap for entry impact before reducing size or skipping.

SHYFT_GRPC_ENABLED=true

Enable gRPC wallet swap stream.

SHYFT_RABBITSTREAM_ENABLED=true

Enable RabbitStream wallet swap stream.

RUST_SIDECAR_ENABLED=true

Enable the Rust pump.fun sidecar feed.

USE_JITO_DIRECT=true

Allow direct Jito BlockEngine bundle submission.

JUPITER_QUOTE_MIN_GAP_MS=650

Throttle Jupiter quote calls across buys, sells, and risk checks.

MAX_OPEN_POSITIONS=3

Limit simultaneous open token positions.
